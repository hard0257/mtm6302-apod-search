# NASA APOD Search - Static Prototype

## Assignment 3: Static Prototype

For this assignment, I created a static prototype for my NASA APOD Search web app using HTML and CSS. The prototype is based on my visual mockup from Assignment 2 and shows the main pages and user flow of the app.

## Pages Created

I created four main pages for the prototype:

Home page
Search APOD page
Favourites page
About APOD page

The Home page is the main landing page where users can see how the app works. The Favourites page shows saved APOD images. The About APOD page explains what the app does and the branding style. The Search APOD page opens when the user clicks the NASA APOD logo on the top left of the Home page.

## User Flow

When the user opens the website, they first see the Home page. From the navigation bar, users can go to Home, Favourites, and About APOD. If the user clicks the NASA APOD text/logo at the top left, it takes them to the Search APOD page.

The Search APOD page includes a date input, a Search APOD button, and an error message example for a future date. This helps show how the app will guide users when they enter an invalid date.

## Steps Taken

I started by creating the Home page layout using HTML and CSS. Then I created separate pages for Favourites, About APOD, and Search APOD. After that, I added navigation links between the pages and made the NASA APOD logo clickable so it opens the Search APOD page.

I also worked on the responsive design so the layout changes for desktop, tablet, and phone views. The tablet and phone views use simpler layouts, larger cards, and a hamburger menu style to match the mockup.

## Resources Used

I used my Assignment 2 visual mockup as the main design reference. I also used space-themed images to match the NASA APOD theme. The prototype was built with HTML and CSS.

## Challenges Faced

The main challenge was making the pages match the mockup on different screen sizes. I had to adjust the spacing, background images, cards, navigation, and mobile layout so the design looked correct on desktop, tablet, and phone.

## Final Notes

This is a static prototype, so the form, buttons, and delete options are only visual and do not have full JavaScript functionality yet. The purpose of this prototype is to show the app layout, design, navigation, and user flow before building the final working version.
